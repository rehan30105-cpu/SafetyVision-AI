1. Project Overview & Objectives

SAFETYVISION AI is an advanced, autonomous workplace safety inspection, PPE compliance verification, and multi-hazard risk monitoring command platform. Built as a Final Year B.Tech Artificial Intelligence & Data Science capstone project, it bridges computer vision with domain-specific spatial reasoning and deterministic safety engineering.

2. End-to-End AI Pipeline Architecture

Camera Stream / Frame → YOLOv8n Detection → Centroid/IoU Person Tracking → Spatial Person-PPE Association → Safety Zone Evaluator → Environmental Context Engine (Machinery/Vehicles/Cones) → Dynamic Risk Engine → Temporal Persistence Confirmation → Event-Driven Evidence Capture → SQLite Persistence → Real-time Telemetry HUD & Dashboard

3. Supported 10 Semantic Model Classes

The system operates on an explicitly trained YOLO model checkpoint with strictly 10 recognized classes:

  1. Hardhat (Compliant Head Protection)
  2. Mask (Compliant Respiratory Protection)
  3. NO-Hardhat (Head Protection Violation)
  4. NO-Mask (Respiratory Protection Violation)
  5. NO-Safety Vest (High-Visibility Vest Violation)
  6. Person (Human Worker Subject)
  7. Safety Cone (Perimeter Demarcation Indicator)
  8. Safety Vest (Compliant High-Visibility Gear)
  9. machinery (Active Heavy Equipment Hazard)
  10. vehicle (Industrial Mobile Equipment / Forklifts)

4. Mathematical Formulations

A. Person-Level PPE Compliance Rate:

$$\text{Compliance} = \sum (w_{\text{item}} \times \mathbb{I}(\text{item} = \text{Present}))$$ Default weights: Hardhat (33.33%), Protective Mask (33.33%), Safety Vest (33.34%).

B. Dynamic Risk Scoring Formula:

$$R_i = \min\left(100, \max\left(0, (P_{\text{ppe}} + P_{\text{context}} + P_{\text{zone}} + P_{\text{duration}}) \times M_{\text{zone}}\right)\right)$$ Where penalties include: Missing Hardhat (+25), Missing Vest (+25), Missing Mask (+15), Synergistic Multi-PPE (+10), Machinery Proximity (+20), Vehicle Proximity (+20), Restricted Zone Breach (+30), and Duration Escalation (+10 to +30).

C. Site Safety Score:

$$\text{Safety Score} = 100 - (0.35 \times \overline{\text{Risk}} + 0.35 \times (100 - \text{Compliance}) + 0.30 \times \min(100, \text{Critical} \times 15))$$

5. Technical Stack & Dependencies

  • Backend: Python 3.10, Flask 3.1, SQLite3
  • Computer Vision & DL: PyTorch 2.14, Ultralytics YOLOv8n, OpenCV 4.11
  • Report Compilation: ReportLab 5.0 (Automated Vector PDF)
  • Frontend: Vanilla HTML5/CSS3, JavaScript ES6+, HTML5 Canvas, Web Audio API, Chart.js

6. Project Limitations & Future Directions

  • 2D vs 3D Proximity: Distances are computed as Euclidean pixel approximations in 2D camera plane. Future expansion includes camera intrinsic calibration and 3D point cloud LiDAR fusion.
  • Extreme Occlusion: Temporary occlusions are bridged for 30 frames via tracking memory; multi-camera cross-view ReID is planned for future work.
